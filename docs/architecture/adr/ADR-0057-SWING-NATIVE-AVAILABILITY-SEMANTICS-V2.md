# ADR-0057 — Swing Native availability semantics V2

**Status:** Approved for bounded Phase C correction by Sponsor, 2026-09-22.
**Decision authority:** Consolidated Phase C availability correction and live requalification.
**Predecessor:** Historical Native Discovery V0 / run schema V1, preserved without reinterpretation.
**Contract:** [Swing Native Discovery availability V2](../interfaces/KRONOS-SWING-NATIVE-DISCOVERY-AVAILABILITY-V2.md).

## Decision

Prospective Native Discovery distinguishes an affirmative, fully evidenced negative setup from unavailable required evidence. NSE weekly opposition and MCX four-hour structural failure are completed blocked assessments, never fresh Probables. Missing Daily, weekly, four-hour or one-hour facts still fail closed; a veto cannot conceal an independent missing fact. Insufficient 205-week NSE foundation history is an explicit ineligible limitation with actual and required counts, not a waived SMA200.

Daily and four-hour pivot facts use a fixed 60 completed-bar ceiling rather than the historical 30-bar window, for the entire relevant population without selecting for a trading outcome. The strict radius-one/radius-two confirmation, exact source and contract lineage, calendar completion, moving averages and all downstream promotion, Risk, Sponsor and lifecycle rules remain intact. The Swing reference lookup maps the one canonical `BANK NIFTY` identity to the calendar applicability subject `BANKNIFTY` without changing either published identity or session authority.

The successor Native policy and run schema are version-dispatched. Historical records, hashes, policies, readers and meanings remain byte-exact. Unknown and mixed versions fail closed. No additional trading authority is created.

## Validation and boundary

Retained-data replay must account for all 98 instruments and every required fact, including independent failures hidden by an earlier veto. Isolated owning and affected protected suites must pass before publication. A fresh market run and production runtime replacement require the separately stated operational gates of the same Sponsor authorization. No historical evidence rewrite, Provider reconnect, fabricated candidate, or MCX Step-31 commissioning is authorized.

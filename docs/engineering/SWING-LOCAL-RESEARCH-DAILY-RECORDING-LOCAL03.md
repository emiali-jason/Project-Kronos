# Swing LOCAL-03 — retained daily research and Opportunity Journey

Status: isolated engineering candidate; not deployed.

Authority: Sponsor LOCAL-03 order, 19 October2026, and frozen local WO-08 master plan. Methodology KRONOS-NSE-LOCAL-RESEARCH-1.0 is unchanged.

LOCAL-03 uses the existing commissioned WO-12 Record store, nonblocking process flock, worker, immutable Local original owner, six-sheet workbook exporter and Browser server pulse. It adds no Provider/model/database/runtime/scheduler service.

Manual Record Today's Research uses retained facts only. Historical Research Update preserves its acquiring behavior and remains a separately labelled action.

A daily BASE is selected by exact Asia/Kolkata calendar date under the existing store transaction. A deterministic retained source-cut digest prevents duplicate publication. Later evidence creates an immutable linked SUPPLEMENT; old artifact bytes and receipts remain unchanged. The original workbook has the existing six sheets plus additive Local_Research when Local observations/missing assessments exist. Each original/scenario row has stable identity; separate snapshot versions intentionally repeat retained context without creating another original observation.

A frozen DAILY_PREPARED intent, artifact hash/path, source references and readback allow recovery of an interrupted publication without taking a new cut or minting a second BASE. Immutable DAILY_ATTEMPT receipts preserve success/failure; identical operation UUID replays its result without new work.

The automatic trigger is a cheap due-date check in existing SERVER_PULSE after READY. It registers one task on the existing executor, not a second scheduler. It obtains an OPEN-only SWING_RESEARCH root ticket and shares ordinary Exit registration locking. Accepted work remains counted through final publication/failure bookkeeping. BUSY/fenced/stopped dispatch does not write. Quiescence prevents new work; ordinary Exit accounts for the worker; governed drain/final proof includes research closure. No maintenance deadline is extended.

Due dates: today at/after23:00IST; yesterday before23:00IST. Catch-up starts at original commissioning and handles current due day first, then older dates, one per worker task. One attempt/date/epoch; no error loop. Restart reevaluates retained sources and recovers frozen intent. Later post23 events are supplemented on the next retained-only manual action or next catch-up epoch, not silently discarded. No acquiring historical replay/UPDATE occurs.

Source and time: immutable records retain source identity, event time and capture time when authoritative; unknown event/capture time stays explicit. Native manifests and all exact artifacts are preserved by hash/reference, streaming large fact files instead of decoding all historical MTF data. Only target-day Native evidence is typed-loaded. Publication ancestry and before/after control are checked. Local originals use the existing validation owner and its fenced cached read; Browser GETs never rerun local mathematics.

Historical day exports explicitly state RETAINED_SNAPSHOT_WITH_TIMESTAMPED_MONTH_CONTEXT_NOT_HISTORICAL_ASOF. Catch-up cannot invent a missing past live state or an unavailable outcome. Current source match is labelled MATCHES_RETAINED_PUBLICATION_NOT_CURRENTNESS_CERTIFICATION. No Review/V2/position/trading authority is acquired.

Journey contains only existing Secondary Review-and-later Local originals, exact Native/publication/assessment binding, method, source/assessment timestamps, direction/disagreement, all three horizons and original scenarios. Existing origin/milestone/decision/lifecycle links are used where exact; an unbound origin is UNRESOLVED, never inferred from symbol. Full Native discovery evidence remains in daily archival references, not promoted into Sponsor Journey as an eligible opportunity.

LOCAL-04 outcome measurement is not implemented. Release B still needs LOCAL-04 plus exact composed qualification, EA-Swing/PCP approval, release-policy reconciliation, rollback/installation/restoration/read-only smoke plan and separate Sponsor operational authorization. Prior Pine exceptions cannot transfer.

## Composition and ownership

Existing owners remain SwingRunPublication, SwingOpportunitiesApplication, SwingProspectiveResearchApplication, SwingLocalAnalysisWorkflow, SwingResearchControl, ProspectiveResearchStore and the Browser composition. Additive source-cut API: `SwingRunPublication.retained_daily_sources(date)` through `SwingOpportunitiesApplication.retained_daily_research_sources(date)`. It returns immutable-source archival descriptors, not a new current analytical snapshot. Provider, Market, validation, position and execution authority do not transfer.

New immutable Record kinds are DAILY_PREPARED, DAILY_PUBLICATION and DAILY_ATTEMPT in the existing WO-12 store. Their recording policy is KRONOS-SWING-RETAINED-DAILY-1.0. DAILY_PUBLICATION uses publication_kind=BASE/SUPPLEMENT, zero-based sequence, prior_publication, prepared_identity, source_digest, source_cut_at, published_at, exact workbook path/hash/size, original source references, Native references, runtime identity and coverage. Legacy records are read under their existing contracts; no migration/rewrite.

Recorder capacity bounds fail explicitly: 5000 retained source records, 5000 inbox envelopes, 10000 publication ancestors, 3660 catch-up calendar days, 4MiB typed Native payload and 16MiB Browser workbook download. These are resource bounds, not analytical eligibility rules. No size cap permits truncating evidence into a false complete result. Legacy envelopes without capture-time authority remain explicitly unavailable; filesystem mtime is never substituted.

The existing six workbook sheets retain their columns, types and formula-free safe serialization. Local_Research is an additive seventh sheet only when the optional local contract is present; original/scenario identity prevents duplicate rows in one export. Historical receipted workbook bytes are never modified by daily publication. Each successor snapshot deliberately contains retained month context; it is not a deduplicated cross-file fact table or a historical market replay.

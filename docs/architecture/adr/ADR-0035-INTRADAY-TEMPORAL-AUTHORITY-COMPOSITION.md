# ADR-0035 — Machine completion and independent visual contradiction composition

**Status:** Sponsor-approved bounded decision; engineering candidate, publication pending.
**Date:** 2026-09-10
**Authority:** Sponsor direct authorization for WO-07E final temporal authority composition.
**Scope:** Intraday chart correspondence, Analyst Protocol and isolated qualification only.

## Decision and bounded supersession

This supersedes only ADR-0033's unconditional rejection of forming UNKNOWN for
native panels with independently validated machine completion. ADR-0033 remains
historical; its schema, source binding, visible contradiction and exclusion rules
otherwise remain in force. Header 1.1.0 and exact question contracts are unchanged.

Machine authority validates the retained selected candle's source integrity,
subject/contract, COMPLETE status, lawful boundary, exchange calendar/session,
exact endpoints, trading date and canonical timezone. Analyst observations never
supply or override this machine proof. Invalid/missing machine authority remains
fail-closed, even with an affirmative visual compatibility claim.

Visual authority independently reports readable identity, timeframe, core chart
content, full right edge and temporal axis, relevant qualified region, readable
labels and supported later/other contradiction findings. context_sufficient
means sufficient evidence to detect material visible contradiction to the Review;
it does not demand invisible final-candle completion proof from static pixels.
Cropped/unreadable context, an indistinguishable qualified region or an unassessable
contradiction check remains false/null and unverifiable.

Native forming UNKNOWN may pass temporal composition only with independently
validated machine completion, context_sufficient=true, readable labels and basis,
full coverage and later_evidence=ABSENT / other_contradiction=ABSENT. Exclusion
fields must all be null for UNKNOWN. UNKNOWN is retained as UNKNOWN; completion
may remain null. No exact visual timestamp is fabricated. Final native
CONFIRMED_COMPATIBLE additionally requires identity/core and overall validation.
Machine failure must not masquerade as an independently visible contradiction.

Affirmative forming/live/countdown evidence remains PRESENT and subject to the
existing qualified-region exclusion rules. Later/future, stale or conflicting
visible evidence cannot be erased by machine authority. No heuristic or prose
parser converts explicit context_sufficient=false into true.

International reference panels cannot borrow native completion authority. Their
existing unknown-forming fail-closed behavior and SUPPORTING_VISUAL_CONTEXT_ONLY /
NOT_INDEPENDENTLY_ESTABLISHED status remain unchanged. Exact native MCX contract
selection, stable family visual authority and NATGAS commissioning HELD persist.

## Evidence, protocol and operating limits

The updated Protocol explicitly distinguishes pixel contradiction sufficiency
from invisible completion metadata. This clarifies existing fields; it does not
change Q1-Q10/R-M-X meaning, strict schemas, distinct visible_labels, Q6/Q9 anchor
NOT_ESTABLISHED, one-candidate PDF transport or 98/98 identity publication.
Existing PDFs, Answers and receipts remain immutable. No retrospective file
rewrite, re-import or automatic replacement observation occurs.

The exact revised LUPIN Answer retains false on every panel. Its prose attributes
that choice to pixel-completion uncertainty, but there is no governed structured
reason discriminator authorizing reinterpretation. It remains historical rejected
evidence. A separately labelled constructed successor with true contradiction
sufficiency and UNKNOWN completion qualifies the corrected deterministic behavior;
this is not a new real Analyst observation or empirical E2E acceptance.

Prior completed higher-timeframe context and lawful 09:30 Opening remain available.
No admission, methodology 2.2.0, Narrow CPR, Review population, research-window,
trading, broker, Provider or runtime authority changes. Batch compilation is
separate. Publication and runtime loading require separate Sponsor gates.

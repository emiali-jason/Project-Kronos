# Intraday Contract and State Ownership Registry

**Status:** WO-03 Native Discovery V0 boundary

| Boundary | Owner | Consequence authority |
|---|---|---|
| Universe | Intraday | Native analytical membership only |
| Native Discovery | Intraday | Factual evaluability, candidate-contract state, bounded reasons and run accounting; predicates deferred |
| Analytical Promotion | Intraday | Promotion only; criteria deferred |
| Trade Construction | Intraday | Plan construction only; no Risk permission |
| Risk | DOMAIN-007 | Risk permission/denial only |
| Entry Timing | DOMAIN-004 | Entry-timing state only |
| Objective Lifecycle | DOMAIN-005 | Model-trade lifecycle only |
| Sponsor Position | DOMAIN-005 sponsor-position boundary | PAPER/LIVE/IGNORE position record only |
| Notifications | Product adapter over Platform notification capability | Intraday notification projection only |
| Journal | Intraday journal over Platform persistence/audit capability | Intraday facts and outcomes only |
| Browser/Dashboard | Product route/projection | Read-only presentation; no state authority |

The boundaries are explicitly non-equivalent:

- Discovery ≠ Promotion.
- Promotion ≠ Entry.
- Construction ≠ Risk.
- Risk ≠ Entry Timing.
- Entry Timing ≠ Lifecycle.
- Objective Lifecycle ≠ Sponsor Position.

This registry does not invent unfrozen states, transition predicates, or
numerical values.

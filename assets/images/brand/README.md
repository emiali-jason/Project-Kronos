# KRONOS brand assets

`kronos-logo-master.png` is the Sponsor-approved full-resolution master artwork.
It is retained byte-for-byte and is not loaded by the Browser shell.

`kronos-brand-mark.png` is the optimized 512 px UI mark derived mechanically
from the master crop `(237, 10, 1017, 790)`. It isolates the approved
K/hourglass/clock identity for the sidebar and macOS application icon.

`kronos-favicon.png` is the optimized 64 px favicon derived from the same UI
mark. Derived assets contain no EXIF or other ancillary metadata.

## Runtime behavior

Resolution iterates only the 98 governed members. An extra Provider, canonical,
Swing, or reference identity never enters. Missing canonical identity preserves
membership and returns CANONICAL_BINDING_UNAVAILABLE. Missing Provider binding
preserves membership and the RuntimeInstrument, but makes runtime consumption
fail closed. WO-03 Discovery must evaluate availability per member.

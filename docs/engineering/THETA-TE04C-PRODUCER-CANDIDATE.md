`V3QuestionProducer(workflow, target_authority, synthetic_methodology=...).create()`
connects the existing Theta workflow/store to the frozen TE-03A adapter and TE-04A
contract constructors. It reuses TE-02 rendering/archive/safe publication and the
TE-04B trusted `retain_question_batch` / `select_question_batch` seams. There is
no new Browser route or default runtime activation. Existing V1/V2 commissioning
and Browser presentation remain on their historical path until separately enrolled.

Genuine methodology authority is **NOT_ESTABLISHED**. This candidate admits only
an explicit synthetic fixture with qualification mode enabled, a SYNTHETIC
descriptor, and instructions marked SYNTHETIC / NOT FOR GENUINE FORECASTING.
Supplying a descriptor cannot enable genuine commissioning. There is no new
methodology approval flag, automatic enrollment or fallback to old authority.
An approved genuine methodology dependency remains a later governed prerequisite.

The target adapter is the existing reviewed TE-03A consumer, with authentic CA
review `KRONOS-CA-TE03A-20261012`, current authority SHA-256
`bfd2f9c50c823455e124cccf50722d05a92cacaf8665d6b6968d1327940dda1d`.

## Identity and currentness

Five canonical V3 Questions bind their exact commodity/canonical subject, cycle,
commodity and shared Macro revisions/hashes, exact owner targets/price units,
public target and methodology descriptors, instructions and individual T0.
Question version 3.0.0 determines the expected Answer 3.0.0 via the frozen
TE-04A definition; no extra field is invented in the closed Question contract.
The matching Answer identity/version and exact return filename also appear in
the PDF and generated schema/template.

Identical selected inputs reuse each child's original Question/T0. Changed
commodity chart inputs replace only that child's Question. Changed shared Macro
rebinds all five. New methodology instructions/descriptor or exact target inputs
cannot reuse an old Question. The combined batch remains a convenience wrapper,
not a replacement for individual identities. No common-T0 normalization occurs.

`selected()` reads complete retained evidence and current bindings without
acceptance, re-T0, publication or selection writes. Descriptor, exact target,
instructions, authority validity and chart changes invalidate currentness.
Retention and final selection use the existing TE-04B service. Rendering happens
outside its lock; current inputs are rechecked before publication and selection.
A concurrent chart change cannot silently select stale evidence. Historical
intact artifacts are not deleted or rewritten after a later admission failure.

## Transport and publication

One deterministic ZIP contains:

- five canonical Questions and five readable individual PDFs;
- five original commodity image artifacts and ONE shared original Macro artifact;
- one combined Answer template and one exact Question-bound closed JSON Schema;
- producer semantic rules generated from the frozen TE-04A definition;
- manual research/return instructions, batch descriptor and checksum manifest.

Macro is repeated visually inside the self-contained PDFs, but its original
standalone artifact is stored once. Original PNG/JPEG bytes are never modified.
The template's null placeholders are deliberately invalid as completed Answers.
JSON Schema supplies structural checks; generated rules and unchanged validators
also enforce chronology, exact decimals and evidence-graph semantics.

The existing TE-02 deep research mandate is retained. Only legacy machine Answer
directions are replaced. No response-speed deadline is introduced; source
availability remains at/before each T0 and later truthful retrieval is permitted.
V3 PDF presentation uses a projection only, never canonical schema conversion.
Legacy default renderer output is checked against retained synthetic TE-02 PDFs.

The producer uses `workflow.outbox`, whose existing default is the Sponsor-frozen
`KRONOS REVIEW PACK/Theta Earners/KRONOS QUESTIONS`. This slice never writes there:
qualification supplies disposable directories. Existing no-follow directory/file
primitives, no-clobber atomic ZIP publication and readback are retained. ZIP name
binds exact cycle/batch and is Sponsor-readable. No directory order or mtime
selects authority. No individual partial file is presented as a complete ZIP.
The V3 contract requires all five subjects; missing input blocks the combined pack.

template/schema parity, deterministic ZIP rebuild, replay and restart, per-child
T0 reuse, chart/target/methodology changes, corruption, symlink/no-clobber failures,
unreviewed target rejection, genuine methodology hold and render-time races.

producer, fills only Analyst slots, imports one combined Answer through unchanged

`output/theta-te04c-closure/`. PDF QA includes actual raster inspection; structural
text checks alone are insufficient. All tests run under `tools/kronos_test.py`,
denying production stores, credentials and external networking.

change; it does not alter the frozen TE-03A authority. The TE-04B test option
registry receives one additive TE-04C artifact destination option. Frozen TE-04A
definitions and TE-04B intake source remain byte-identical.

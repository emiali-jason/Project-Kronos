## Versioning and observation objects

The companion JSON freezes exact identities, wording, ordered questions, enums,
timeframes and observation fields. All new visual question/Answer contracts are
version 2.0.0. Review workflow V2 and visual-question V2 are different version axes:
historical Review workflow V2 packs contain visual V1 questions with retained
artifact schema 2.0.0. New NSE Review Question Pack and Imported Visual Evidence
artifacts use schema 3.0.0 while their visual question/Answer contract is 2.0.0.
MCX paired artifacts advance separately from 1.0.0 to 2.0.0. This preserves exact
historical workflow bytes and downstream identities.
Factories retain explicit V1 support; current operational generation selects
visual V2. The existing Review stores, codecs and transport services are extended,
not replaced with another Question/Answer engine or another evidence store.

Both families use the same seven-field observation object. MCX retains its
family-specific envelope: reference_answers R1-R5, native_answers M1-M5,
cross_market_answers X1-X4, and escape_hatch_answer X5. These are exactly fifteen
observations. V1's three-field M01-M10/R01-R06/X01 records remain separate.
New optional codec fields are omitted entirely from legacy serialization; no
historical migration or byte rewrite occurs.

OBSERVED requires a permitted answer, full ordered question timeframe scope and
independent visible basis. PARTIAL requires a nonempty permitted timeframe subset,
basis and a bounded reason. Absent statuses have null answer/basis and no visible
timeframes. UNCLEAR and NOT_OBSERVABLE are answers where expressly allowed;
they are not neutral votes. INVALID templates cannot be imported as valid evidence.
Q10/X5 MATERIAL_OBSERVATION requires why_not_covered_elsewhere; NONE requires null.
Explanations cannot appear on other questions. Exact field sets/order/enums and
schema/question-set pairings reject masquerade. Machine envelope IDs are prefilled;
Analyst observed identities are placeholders until independently supplied.

new evidence can persist. Missing source means no supplied level, not zero.

Q6/Q9/M5 answers. Missing optional overlays do not invalidate unrelated observations;
the affected answer must remain unobservable/unclear/unavailable. Missing machine
level authority cannot support substantive NSE Q6/Q9 or MCX M5 answers.

threshold or future confirmation. X1-X4 require both sides' lawful WO-07B evidence.
Wrong/future/forming/stale/foreign-session sources do not become synchronized.

unavailable: WO-07C does not invent them or relax WO-07B to make an import pass.

Volume may contribute qualitative visible basis when meaningful; exact volume,

(BUY/SELL/WATCH/READY/confidence/recommendation) remain excluded by WO-07B.
